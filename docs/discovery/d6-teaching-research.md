# Discovery — teacher eligibility in India, state by state

Researched **2026-09-27** by open-ended search, the way a B.Ed.-holding candidate
actually does it: type `TGT recruitment 2026`, follow the breadcrumbs to whichever
board the state uses, then open that board's own notice. Everything below was
assembled by opening the conducting body's site or its notification PDF, not by
reading a coaching summary.

**Records written: 18.** Slugs are in `content/exams/d6-*.md`.

This note exists because the search confirmed a thing no single page states: the
question "what do I have to pass to become a teacher here?" has three different
answers depending on which *level* you mean, and they are administered by three
different bodies per state, on three different schedules. There is no map. This
file is the map.

---

## 1. The trap nobody warns you about

A student searches "TET" and gets one test. In practice there are **three
separate gates**, and passing one does nothing for the other two:

| Gate | What it buys you | Who runs it |
| --- | --- | --- |
| **TET-family** (classroom teaching) | Eligibility to be *appointed* primary/upper-primary/secondary teacher | a state board, or CBSE centrally |
| **SET** (college teaching) | Eligibility to be *appointed* Assistant Professor | a state agency, or UGC NET / CSIR-NET |
| **Recruitment** (the job) | An actual post, with vacancies | a PSC, a staff selection board, or a department |

The rule that generates the most confusion: **the qualifying exam is not the job.**
A TET or SET certificate is a key, and every state opens a *different* door with
it, under a *different* board, on a *different* schedule. Concretely, in this
pass:

- **Bihar.** The BSEB `STET` is a 2026 test whose *examination date the board has
  still not published*, while `TRE-4.0` (BPSC, 32,388 posts) opened registration
  on 25 September 2026. A candidate can be eligible in name and hireable in
  practice only after a test whose date does not exist yet.
- **Karnataka.** The KEA's Social Welfare Residential School Teacher recruitment
  requires "the TET conducted by either the Government of Karnataka or the
  Government of India" — but **Karnataka does not appear to run a TET at all.**
  The state gate for college teaching is KSET, run by the same authority, and the
  same authority runs the recruitment. One body, three products.
- **Maharashtra.** The 30,209-post Shikshak Bharti 2026 advertisement lists
  `D.Ed./D.El.Ed./B.Ed.` **plus** `TAIT 2025` **plus** `Maharashtra TET` for
  classes 1–8. Three separate qualifications for one job.
- **Odisha.** There are **two** different eligibility tests, not one. `OTET`
  covers classes I–VIII and was held on 28 June 2026. `OSSTET` covers the
  secondary stage (Paper I classes IX–X, Paper II classes XI–XII) and is on
  **30 September 2026** — a completely separate notification, a separate fee, a
  separate paper. Searching "Odisha TET" finds the wrong one for a secondary
  candidate.

The **Special TET** family is a fourth thing that will confuse anyone reading old
advice. Five states now run a Supreme-Court-driven *Special TET* for serving
teachers who predate the RTE Act: Uttar Pradesh (UPESSC, 3 Nov 2026), Andhra
Pradesh (APCSE, 11–21 Oct 2026), Tamil Nadu (TRB, 4–5 July 2026), Telangana
(TRB/DSE, 7 & 11 Sept 2026) and Assam (SCERT/SSA, 28 June 2026). It is **not**
the general TET and does not substitute for it.

**National, for every state that does not run its own:**

| Test | Conducted by | Official URL |
| --- | --- | --- |
| **UGC-NET** | National Testing Agency, for UGC | `ugcnet.nta.nic.in` |
| **Joint CSIR-UGC NET** (science; Lectureship + JRF) | NTA with CSIR | `csirnet.nta.nic.in` |

**The SET trap.** A SET qualifies you for Assistant Professor in **its own state
only.** This is not folklore — it is stated on the conducting bodies' own sites.
Maharashtra's portal: "after June 2002, SET qualified candidates shall be eligible
to apply for the post of Assistant Professor only in the Universities/Colleges
belonging to the same state whose SET Examination they have cleared." MS
University of Baroda's office page says the same. And every SET carries **no JRF**;
only NET and CSIR-NET do. A candidate optimising for a fellowship must sit NET.

**The SET eligibility trap.** No SET-qualified candidate is appointed by passing
it. The bodies say this in the same breath: you are held "eligible … provided he/she
fulfils other academic qualifications prescribed for the post … and is selected by
the respective Selection Committee."

## 6. Multi-day traps, concretely

Ten of the eighteen records deliberately carry **no** `exam_date`. Each of these
is a single "exam" that runs over several days, or has no published date:

| Test | Published window | Days |
| --- | --- | --- |
| UGC-NET, Dec 2026 cycle | 14–19 Dec 2026 (buffer 20–21 Dec) | 6 |
| HP TET November 2026 | 22 Nov – 6 Dec 2026 | 15 |
| AP Special TET 2026 | 11–21 Oct 2026 | 11 |
| Joint CSIR-UGC NET, Dec 2026 cycle | 20–21 Dec 2026 | 2 |
| CTET, December 2026 | 12–13 Dec 2026 | 2 |
| TG SET 2026 | 28–30 Sep 2026 | 3 |
| UPTET 2026 (completed) | 2, 3, 4 Jul 2026 | 3 |
| REET 2026 mains (completed) | 17–20 Jan 2026 | 4 |

Picking "the first day" or "the last day" of any of these would be wrong. Note also
that several states run **one test for several posts simultaneously** — HPBOSE's
November TET covers TGT Arts, Non-Medical and Medical, TGT Sanskrit, JBT, TGT
Hindi/Punjabi/Urdu and two Special Educator levels in a single application, and
HTET runs three levels. A state can also run one test for two *different* papers
on the same day, as OSSTET does: "one sitting both Paper-I and Paper-II, 09.00 to
11.30".

## 7. Postponements and revisions, in one place

Four of the exams in this pass moved. Anyone reading a coaching summary will be
reading stale dates.

- **MH SET 41st** — postponed **three times**. Advertised for 26 July 2026,
  admit cards issued, test did not happen; the university's portal now announces
  **25 October 2026** and carries a corrigendum and a new prospectus. The portal
  also still shows the old July prospectus alongside the new one.
- **Rajasthan SET 2026** — Notification-01/2026 (11 Jun 2026) fixed 6 September;
  Notification-02/2026 (27 Jun 2026) moved it to 13 September and added two
  subjects (35 → 37). Held 13 September.
- **HTET** — advertised for 13–14 June, then 13–14 July, then **4–5 July 2026**.
  Three dates in three announcements.
- **OTET (Odisha)** — 29 May → 21 June → **28 June 2026**. Two changes.
- **MP TET (2026)** — this one did *not* move, which is itself worth noting: it was
  re-launched on 17 August 2026 in compliance with the Supreme Court's 1 September
  2025 orders in Civil Appeals 1385 and 1386 of 2025.
- **CTET edition numbering** — CBSE's notice of 8 May 2026 calls the 6 September
  2026 test the 22nd edition; its notice of 14 September 2026 also calls the
  December test the 22nd edition. The two do not agree, so no edition number is
  carried in the December record.

## 8. Dead ends and domains that would not answer

Being explicit, because the next person will otherwise waste an hour.

- **Scanned-PDF-only notices: Odisha.** BSE Odisha publishes its OSSTET
  notification and its step-by-step application instructions as **scanned image
  PDFs** with a visible "Scanned with OKEN Scanner" footer. The dates *were*
  legible and are corroborated by the board's separate, text-based press release,
  so the record carries the 30 September 2026 exam date and 3–23 August
  registration — but nothing else was read out of the scans, and no fee or
  qualification was transcribed from them. Assam's SCERT pages are the same
  pattern: every syllabus and advertisement download is served as `swf-image`.
- **Telangana SET portal** — `tset.telangana.gov.in` **did not respond** to a
  direct request on 27 September 2026 (transport error, not a 404). The record
  therefore uses Osmania University's own domain and says so in the body. The TG
  SET 2026 cycle is real and its CBT is 28–30 September; only the portal could not
  be confirmed. **This is the one record whose `official_url` is a fallback.**
- **Bihar PSC** — `www.bpsc.bih.nic.in` **timed out**. TRE-4.0's dates come from
  press reporting of a BPSC announcement, not from the site.
- **CBSE CTET notice PDF** — served as raw PDF bytes; the text was read from the
  indexed copy rather than the file itself.
- **BSEB STET portal** — `bsebstet.org` loaded fine but was **still showing the
  2025 cycle** (2025 result, admit card, objection links) on 27 September 2026,
  so the 2026 notice has to be reached through the BVPS homepage.
- **Web search returned HTTP 429** partway through the last research round. The
  Telangana SET URL and the BPSC advertisement number could not be closed out by
  a further search, which is why those two records are hedged as described above.
- **Not reached at all:** Arunachal Pradesh, Sikkim, Kerala, J&K and Ladakh. Kerala
  is the interesting omission — it is widely believed to have no state SET and to
  rely on NET; that was not confirmed here.
- **No live cycle found** (candidate should assume the state's own site is
  authoritative): **TNSET** — Manonmaniam Sundaranar University's site carried no
  TNSET notification when checked; only its PhD entrance. **GTET (Gujarat)** — no
  state TET located. **Karnataka TET** — none located, yet KEA's own recruitment
  notice requires one from Karnataka *or* the Centre, which is an open question
  worth chasing.

## 10. Two things that would improve the schema

Not implemented — out of scope for a discovery pass — but both came up repeatedly
enough to be worth recording:

1. **`qualifies_for` / `gate_type`.** Three of the eighteen records are
   *recruitment*, not eligibility: BPSC TRE-4.0, the Karnataka Social Welfare
   residential-school teacher drive, and — in existing records — CG Vyapam's
   Assistant Teacher and Teacher advertisements. A field distinguishing "this
   makes you eligible" from "this is the job" would stop a candidate, or a search
   index, from conflating them. Right now that distinction lives only in the body
   prose of each record.
2. **`supersedes` / `replaces`.** MH SET moved three times and Rajasthan SET
   moved once, each superseding a notification still visible on the body's own
   site. Nothing in the current model records that a published notice has been
   replaced, which is exactly the failure mode a candidate hits in week one.
