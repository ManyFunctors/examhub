No exam date. The online application for Agniveer (SSR), Agniveer (MR) and SSR
(Medical) for INET 2026 was live from 14-03-2026 to 06-04-2026 and Stage-II call-up
letters have been issued, but the portal publishes no single Stage-I date for this
cycle, so the field is omitted. Agniveer (MR) is a separate entry from the Agniveer
MR (Musician) entry, which is a different advertisement with its own application
window. Stage-II call-up letters for the 01/2027 batch were issued in September 2026.
